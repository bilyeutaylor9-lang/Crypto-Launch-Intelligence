# Changelog

## v0.5.0 - Watchtower Alpha

### Major Upgrade

Introduces the Watchtower intelligence layer for autonomous crypto opportunity alerts.

### New Features

- Autonomous Watchtower alert engine
- Daily brief generation
- Persistent alert history
- AI analyst signal review
- External X/news intelligence integration
- High-conviction alert scoring
- Narrative, launch, staking, liquidity, and smart-money alignment checks
- Pre-breakout pattern and trap-pattern monitoring
- Institutional vNext scoring and explainability output

### Why It Matters

Crypto Launch Intelligence can now detect stronger early-stage signals and surface high-conviction projects before they gain wider market attention. Instead of only producing a report when manually scanned, the system can now watch project behavior over time and highlight important changes.

### New Commands

```bash
npm run watchtower
npm run watchtower:daemon
npm run alerts
npm run brief
```

### New Outputs

```txt
reports/alerts.json
reports/daily-brief.json
data/watchtower-alerts.json
data/watchtower-brief.json
```
