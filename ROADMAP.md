# Crypto Launch Intelligence Roadmap

This roadmap turns Crypto Launch Intelligence into a self-learning AI research desk:

```text
discover -> research -> score -> debate -> simulate -> dossier -> alert -> track outcome -> learn
```

The goal is not to create louder signals. The goal is to create accountable research: every thesis should have evidence, confidence, invalidation, and a later outcome grade.

## Month 1: Live Catalyst Radar

Build the time-sensitive event layer.

Deliver:

- Unlock, listing, launch, airdrop, governance, staking, GitHub release, TVL, liquidity, wallet, X, and news event detection
- Urgency windows: `24h`, `72h`, `7d`, `30d`
- Catalyst event feed
- Watchtower alert integration
- Dossier Swarm promotion triggers

Success:

- Every high-priority alert includes a why-now catalyst.
- `reports/catalyst-radar.json` is published to the dashboard.
- Outcome Judge later grades catalyst usefulness.

## Month 2: Real-Time Watchtower Dashboard

Make the public dashboard feel like an intelligence command center.

Deliver:

- Live catalyst feed
- Top dossier cards
- AI Council decision panel
- Outcome Judge performance panel
- Search/filter by project, chain, narrative, urgency
- Why-now timeline

Success:

- A new visitor understands the top opportunities in under 60 seconds.
- Every top card links to raw evidence.
- The dashboard stays readable on mobile.

## Month 3: Historical Backtesting Lab

Turn memory into measurable credibility.

Deliver:

- Backtest by engine
- Backtest by narrative
- Backtest by market regime
- Strong-buy hit rate
- False-positive rate
- Missed-winner analysis
- Strategy leaderboard

Success:

- High-conviction claims include hit rate and sample size.
- Weak engines are visible.
- The project can show where it was right and wrong.

## Month 4: Agent Learning System v2

Make every agent accountable.

Deliver:

- Agent-specific hit rates
- Agent trust weights
- Agent disagreement scoring
- Correct-agent attribution
- Noisy-agent demotion
- Reliable-agent promotion

Success:

- AI Council and Dossier Swarm agents show trust weights.
- Outcome Judge can explain which agents were right.
- Agent performance changes future decisions.

## Month 5: Deep Internet Research Mode

Make the scanner research like an analyst.

Deliver:

- Official docs parsing
- Blog and news parsing
- GitHub release reading
- Governance forum scanning
- Whitepaper summaries
- Tokenomics extraction
- Claim-level citations
- Research freshness score

Success:

- Every top dossier includes sourced claims.
- Old research lowers confidence.
- Unverified claims are clearly marked.

## Month 6: Portfolio Intelligence Layer

Move from ranking tokens to choosing research baskets.

Deliver:

- Sector exposure
- Chain exposure
- Correlation risk
- Conviction buckets
- Risk-adjusted basket builder
- Rotation detection
- Watchlist rebalancing
- Capital allocation guidance

Success:

- Top opportunities are compared against each other.
- Dashboard shows concentration risk.
- Portfolio suggestions include invalidation logic.

## Month 7: Public Product Polish

Make the repository easy to trust, star, fork, and run.

Deliver:

- Hosted dashboard polish
- Screenshots or GIFs
- Quickstart CLI
- Architecture diagram
- Issue templates
- Release notes
- GitHub Actions badges
- Demo workflow

Success:

- New users can run `npm run demo` without help.
- The README shows real outputs.
- The repo has clear contribution paths.

## Month 8: Autonomous Research Desk

Tie everything together into a self-running research loop.

Deliver:

- Scheduled scans
- Automatic catalyst alerts
- Daily and weekly research briefs
- Self-review loop
- Agent performance report
- Dashboard publishing
- Top 10 opportunities this week
- Biggest risks this week
- What changed since last scan

Success:

- The system can run unattended.
- Every alert is later outcome-graded.
- Weekly briefs explain what changed and why.

## Execution Rules

- Keep the demo no-key and reproducible.
- Prefer free data sources first.
- Add paid APIs only as optional accelerators.
- Do not promote high-conviction ideas without evidence and invalidation.
- Measure every major engine against outcomes.
